## โครงสร้างและอัปโหลด
- dist/ เป็นเว็บ static พร้อมใช้งาน มีindex.html,insure_retire.html,legacy.html,health.html,savings.html พร้อม assets/modules/JSON
- ไฟล์ *-test.mjs และ run-tests.mjs เป็นชุดทดสอบ; docs/ เก็บต้นฉบับและบันทึก ไม่ใช่โฟลเดอร์เผยแพร่
- ไม่รวม .git/ หรือ .openai/ และไม่รวม credential ใด ๆ
- แตก ZIP ในโฟลเดอร์แยก ตรวจ HANDOFF_MANIFEST.json แล้วซิงก์ไฟล์เข้ากับ repository เดิม
- ถ้า repository เดิมมีเว็บสำเนาที่root ให้ตรวจรูปแบบdeployเดิมและซิงก์ไฟล์เว็บrootจากdistให้ตรงกันด้วย อย่าทับrootโดยไม่ตรวจ อย่าลบไฟล์อื่นของrepository
- GitHub Pages: มี .github/workflows/tyinsure-pages-manual.yml ให้กดRun workflowเองเมื่อพร้อมและPagesใช้GitHub Actions แล้ว เผยแพร่เฉพาะdist/ การpushอย่างเดียวไม่ทำให้workflowนี้เผยแพร่
- ตรวจสิทธิ์การเข้าถึงของGitHub Pagesก่อนใช้งาน เพราะอาจต่างจากSiteเดิมที่owner-only อย่าเปลี่ยนสิทธิ์หรือเปิดpublicอัตโนมัติ
- Netlifyถ้าใช้: netlify.toml ตั้งpublish=dist ไม่มีขั้นตอนbuild
